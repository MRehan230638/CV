# ATS Notes

This resume is **ATS-optimized** (not ATS-guaranteed). It uses a single-column structure, standard section headings, plain text bullets, and no tables/text boxes/icons so most applicant tracking systems can parse it reliably.

## Design Choices
- One-column, text-first layout for machine readability.
- Conventional headings (`Professional Summary`, `Education`, `Publications`, `Skills`, etc.) for consistent ATS mapping.
- Keyword alignment for International Relations pathways (foreign policy, geopolitical analysis, diplomacy, strategic studies, international law, human rights, policy analysis, research, and community engagement) without keyword stuffing.
- Focus on verified facts only; unverified contact fields and unsupported claims are intentionally omitted.

## Source and Verification Notes
- Source material used: repository files and the public LinkedIn profile provided by the user.

Because OCR tools were unavailable in this sandbox, details were retained from verifiable visible sources and user-provided LinkedIn facts.

## How to Customize for a Target Role
1. Replace or expand the professional summary with role-specific focus (e.g., policy research assistant, think tank intern, NGO program support).
2. Reorder bullets/sections so the most relevant publication, project, and certifications appear first.
3. Add verified contact fields (email/phone) if available and intended for public sharing.
4. Mirror language from the job description in the `Skills` and `Professional Summary` sections while staying factual.
5. Add new verified experiences with action-oriented bullets and clear scope.
